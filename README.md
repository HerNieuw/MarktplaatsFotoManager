# MarktplaatsFotoManager
Automatisch Kringloop foto-bewerking &amp; archieverings-tool voor Marktplaats




<img width="1533" height="868" alt="Screenshot From 2026-07-30 22-09-07" src="https://github.com/user-attachments/assets/95347a9f-bad5-484f-9667-abdefeb8af0f" />
Kies mappen, logo, watermerk, eventueel een achtergrond kleur of thema.

Halverwege de verwerking kunnen foto's nogmaals bewerkt en gecorrigeert worden via Gimp waarna een arikelnummer toegevoegd kan worden aan het gefotografeerde item.
