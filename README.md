# MarktplaatsFotoManager
Automatisch Kringloop foto-bewerking &amp; archieverings-tool voor Marktplaats

Halverwege de verwerking kunnen fotoś nogmaals bewerkt en gecorrigeert worden via Gimp warna een arikelnummer toegevoegd kan worden aan het gefotografeerde item.
